Privacy Policy: Classroom Pull

Last updated: October 24, 2026

Classroom Pull is a private, personal-use tool built and operated by an individual developer. It is not offered to the public. It is used only by its owner, to view the owner's own Google Classroom information in a spreadsheet.

What data the app accesses

With the owner's explicit consent, the app reads (read-only) the owner's Google Classroom courses, coursework, course materials, announcements and topics. The app performs read operations only and does not create, edit or delete anything in Google Classroom, although Google’s consent screen may describe the coursework permission as including edit access.

How the data is used and stored

Data is used only to produce a spreadsheet for the owner's personal reference. It is stored in the owner's private file storage. It is not sold, shared, published, or disclosed to any third party, and it is not used for advertising or to train AI models.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Stored data can be deleted by deleting the spreadsheet file.
